AI-driven workflow builder (don't confuse it with [AI in workflows](./ai-in-workflows)) is a chat-like UI to build workflows using natural language. 
It works in the “human in the loop” paradigm, proposing changes and applying them only after the user's explicit consent. 
It simplifies workflow-building routines and helps a broader group of engineers within the organization adopt workflows.


Go to "Workflows" -> "+ Create Workflow" to find the AI Assistant:

## Enable AI locally (self-hosted)

The assistant is enabled when either:

1. **Settings → AI** — configure an OpenAI API key and model in the UI (stored securely per tenant), or
2. Environment variables on the frontend / server (`OPENAI_API_KEY` or `OPEN_AI_API_KEY`). Env wins if both are set.

### Via Settings (recommended)

1. Open **Settings → AI** (`/settings?selectedTab=ai`).
2. Paste your OpenAI (or OpenAI-compatible) API key.
3. Choose a model from the list (or type a custom model id) and optionally set Base URL / Organization ID.
4. Click **Save AI settings**. Workflow Builder AI, incident summaries, and **Catalog → Alert codes** description enhance unlock without restarting.

### Via environment

```bash
OPENAI_API_KEY=sk-...
# optional alias also supported:
# OPEN_AI_API_KEY=sk-...
```

Restart the UI after changing env vars (`make stop && make start`, or recreate the frontend container).

Optional LiteLLM / local models: set `OPENAI_BASE_URL` (and the same key vars) on the frontend, or use Base URL in Settings → AI. See [Keep with LiteLLM](/deployment/local-llm/keep-with-litellm).

Use **Test connectivity** on Settings → AI to verify the key and selected model before or after saving.

| Env var / Setting | Purpose | Required |
| --- | --- | --- |
| `OPENAI_API_KEY` or `OPEN_AI_API_KEY` / Settings API key | Unlocks the UI and authenticates CopilotKit | Yes |
| `OPENAI_MODEL_NAME` / Settings model | Model override | No |
| `OPENAI_BASE_URL` / Settings base URL | OpenAI-compatible proxy (e.g. LiteLLM) | No |
| `OPEN_AI_ORGANIZATION_ID` / Settings org ID | OpenAI organization | No |

Full reference: [Configuration](/deployment/configuration#openai).
