## Overview

The **temporal-worker** service polls Temporal task queue `keep-ops` and runs:

### `ListAndZipDirectory`

1. Activity `run_ls` — `ls -la` on a sandboxed path under `/data`
2. Activity `create_zip_from_ls` — write the listing into `/data/output/*.zip`

### `RemediateNvidiaGpu`

1. **Approval** — auto-required for suite L3+ (`long` / `xlong`); or when `wait_for_approval: true`. Escape hatch: `skip_approval: true`
2. **Cordon/drain** — for suite L2+ (`POST` provider-mock `/gpu/server/cordon`). Skip with `skip_cordon: true`
3. Activity `run_dcgm_diag` — mock `POST /gpu/server/diag`, or real `dcgmi diag --json` when `DCGM_DIAG_MODE=real`
4. On **Fail / ISOLATE** — `send_gpu_failure_email`; leave node cordoned and incident open
5. On **Pass / RESET** — `remediate_nvidia_gpu` → `/gpu/server/remediate`
6. Remediation success — `uncordon` (if cordoned) + `resolve_keep_incident`
7. Remediation failure — `send_gpu_failure_email` (node stays cordoned)

Pass `skip_diag: true` to remediate without diagnostics (legacy path).

| Env | Default | Purpose |
| --- | --- | --- |
| `KEEP_API_URL` | `http://host.docker.internal:8080` | Keep API for incident resolve |
| `KEEP_API_KEY` | `keepappkey` | Admin API key |
| `GPU_MOCK_URL` | `http://host.docker.internal:8099` | Provider-mock NVIDIA GPU server |
| `GPU_ALERT_EMAIL_TO` | `ops@ai-dc.local` | Failure email recipient |
| `DCGM_DIAG_MODE` | `mock` | `mock` or `real` (`dcgmi` on the worker) |
| `DCGM_DIAG_REQUIRE_REAL` | unset | If `1`, do not fall back to mock when `dcgmi` is missing |
| `DCGM_DIAG_TIMEOUT_SEC` | `600` | Real `dcgmi` timeout |
| `DCGM_BIN` | `dcgmi` on PATH | Optional absolute path to `dcgmi` |

## Start

```bash
make deps              # Temporal server + temporal-worker + synthetic-checks + provider-mock
# or
make temporal-worker   # keep-ops worker only (server must be up)
```

Temporal UI: http://localhost:8233

`make start` includes these workers via `deps-up`.

## Register in Keep catalog

1. Connect a **Temporal** provider (`localhost:7233`, namespace `default`)
2. Run:

```bash
make register-list-and-zip-catalog
make register-nvidia-gpu-catalog
```

3. Open an incident → **Workflows** → **Start for incident**

Optional incident enrichment for ListAndZip: `list_path=sample`.
