## Overview

The **temporal-worker** service polls Temporal task queue `keep-ops` and runs:

### `ListAndZipDirectory`

1. Activity `run_ls` — `ls -la` on a sandboxed path under `/data`
2. Activity `create_zip_from_ls` — write the listing into `/data/output/*.zip`

### `RemediateNvidiaGpu`

1. Activity `remediate_nvidia_gpu` — `POST` provider-mock `/gpu/server/remediate`
2. On success — `resolve_keep_incident` → Keep `POST /incidents/{id}/status` (`resolved`)
3. On failure — `send_gpu_failure_email` → provider-mock `/gpu/emails`

| Env | Default | Purpose |
| --- | --- | --- |
| `KEEP_API_URL` | `http://host.docker.internal:8080` | Keep API for incident resolve |
| `KEEP_API_KEY` | `keepappkey` | Admin API key |
| `GPU_MOCK_URL` | `http://host.docker.internal:8099` | Provider-mock NVIDIA GPU server |
| `GPU_ALERT_EMAIL_TO` | `ops@ai-dc.local` | Failure email recipient |

## Start

```bash
make deps              # Temporal server + temporal-worker + synthetic-checks + provider-mock
# or
make temporal-worker   # keep-ops worker only (server must be up)
```

Temporal UI: http://localhost:8233

`make start` includes these workers via `deps-up`.

## Register in Keep catalog

1. Connect a **Temporal** provider (`localhost:7233`, namespace `default`)
2. Run:

```bash
make register-list-and-zip-catalog
make register-nvidia-gpu-catalog
```

3. Open an incident → **Workflows** → **Start for incident**

Optional incident enrichment for ListAndZip: `list_path=sample`.
