## Goal

Prove the AI datacenter remediation path:

1. **Provider mock** fires NVIDIA / DCGM Grafana alerts into Keep  
2. Keep correlates them into a **GPU** incident  
3. Keep workflow starts Temporal **`RemediateNvidiaGpu`**  
4. Temporal remediates the **mock NVIDIA GPU server**  
   - Optional: set `wait_for_approval: true` on the Temporal input so Keep **Approvals** must accept before reset  
   - **Success** → resolves the Keep incident  
   - **Failure** → posts a mock ops email (incident stays open)

## One-command setup

`make start` already:

- Starts provider-mock (`:8099`) and the Temporal worker (`RemediateNvidiaGpu`)
- Registers **mock-grafana** + **mock-temporal** into Keep (best-effort)
- Registers **Remediate NVIDIA GPU** in the Temporal catalog
- Registers reserved **NVIDIA_GPU_*** codes under Catalog → Alert codes
- Uploads `examples/workflows/mock-nvidia-gpu-remediate.yml`
- Seeds **Service Topology** (region / datacenter / row / rack / GPU)

To re-run only the GPU demo setup after Keep is up:

```bash
make demo-nvidia-gpu
```

Disable auto-setup: `AUTO_SETUP_NVIDIA_GPU_DEMO=0 make start`

## Fire the demo

1. Mock UI → **Grafana** → **Register**  
2. Mock UI → **Temporal** → **Register Temporal**  
3. Keep → **Service Topology** — filter **NVIDIA GPU Inference** (seeded by `make start`)  
4. Success path: Grafana → **GPU: rule + temp/mem**  
5. Failure path: **NVIDIA GPU server** tab → enable **Force fail**, then re-fire GPU alerts  

## What to check

| Place | Success | Failure (`Force fail`) |
| --- | --- | --- |
| **Incident** | Status becomes **resolved** | Stays open |
| **Incident → Workflows** | Keep workflow + Temporal start | Same |
| **Incident → Overview** | `gpu_remediation=started` | Same |
| **Mock → NVIDIA GPU server** | Remediations show **ok** | Remediations show **fail** |
| **Mock → Failure emails** | Empty (or prior) | New email to `ops@ai-dc.local` |
| **Keep → Service Topology** | `gpu-inference` + `gpu-node-a03` / `rack-12` / `row-a` badge | Same path, incident stays open |
| **Temporal UI** http://localhost:8233 | Workflow `RemediateNvidiaGpu` completed | Completed with `ok=false` |

## Workflow file

[`examples/workflows/mock-nvidia-gpu-remediate.yml`](https://github.com/keephq/keep/blob/main/examples/workflows/mock-nvidia-gpu-remediate.yml)

- Triggers: alert CEL `labels.code.startsWith("NVIDIA_GPU")` **or** incident `created` / `updated` with the same code filter  
- Guard: enrichment `gpu_remediation` not set  
- Action: Temporal `start_workflow` → `RemediateNvidiaGpu` / `keep-ops`  
- Mock payloads set reserved `labels.code` (`NVIDIA_GPU_THERMAL`, `NVIDIA_GPU_MEMORY`, …). Register those codes under [Catalog → Alert codes](/overview/alert-code-catalog) to attach a runbook or auto-run this workflow.  
- Temporal activities call provider-mock `/gpu/server/remediate`, then Keep `/incidents/{id}/status` or `/gpu/emails`
