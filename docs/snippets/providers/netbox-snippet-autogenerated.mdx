## Authentication
This provider requires authentication.
- **netbox_url**: NetBox base URL (required to pull DCIM topology) (required: False, sensitive: False)
- **api_token**: NetBox API token with DCIM/IPAM read permissions (required: False, sensitive: True)
- **verify_ssl**: Verify TLS certificates when calling the NetBox API (required: False, sensitive: False)
- **gpu_name_pattern**: Regex matching GPU inventory items and modules (required: False, sensitive: False)

Certain scopes may be required to perform specific actions or queries via the provider. Below is a summary of relevant scopes and their use cases:
- **dcim_read**: Read DCIM and IPAM via the NetBox API (required to sync topology).  ([Documentation](https://netboxlabs.com/docs/netbox/en/stable/integrations/rest-api/))



## In workflows

This provider can't be used as a "step" or "action" in workflows. If you want to use it, please let us know by creating an issue in the [GitHub repository](https://github.com/keephq/keep/issues).
